# Noor-e-Saad

### Har Lamha Noor Se Roshan

A modern, responsive event décor and event-organizing website designed
for **Noor-e-Saad**. The site presents wedding décor, mehndi and dholki
setups, birthdays, baby showers, corporate events, and related event
styling services through a polished single-page experience.

## ✨ Highlights

-   Elegant luxury-inspired dark theme with gold, rose, and emerald
    accents
-   Responsive layout for desktop, tablet, and mobile
-   Sticky navigation with responsive mobile menu
-   Animated hero section with interactive visual effects
-   Service showcase with interactive cards
-   Event gallery with category filters
-   Interactive gallery lightbox with next/previous navigation
-   Event planning process section
-   Service packages with starting prices
-   Interactive event cost estimator
-   Booking/request form with validation
-   WhatsApp quote/request flow
-   Testimonials carousel
-   FAQ accordion
-   Floating WhatsApp contact button
-   Scroll progress indicator
-   Animated counters and section reveal effects
-   Accessibility-focused focus states and reduced-motion support
-   SEO-friendly title and meta description
-   Inline SVG artwork and favicon
-   No framework or build system required

## 🛠️ Technologies

-   HTML5
-   CSS3
-   Vanilla JavaScript
-   SVG
-   Google Fonts
    -   Fraunces
    -   Figtree

The project is intentionally built as a lightweight single-page website
without React, Vue, Bootstrap, Tailwind, or a backend.

## 📁 Project Structure

``` text
noor-e-saad/
└── index.html
```

The current implementation keeps the CSS, JavaScript, SVG artwork, and
page content inside `index.html`, making the project easy to deploy as a
static website.

## 🚀 Run Locally

No installation or build process is required.

1.  Clone the repository:

``` bash
git clone https://github.com/YOUR-USERNAME/noor-e-saad.git
```

2.  Open the project folder.
3.  Open `index.html` in a browser.

For development, you can also use the VS Code Live Server extension.

## 🌐 Deployment

Because this is a static HTML/CSS/JavaScript project, it can be deployed
on services such as:

-   GitHub Pages
-   Vercel
-   Netlify
-   Any standard static web hosting

### GitHub Pages

1.  Push the project to a GitHub repository.
2.  Open **Settings → Pages**.
3.  Select **Deploy from a branch**.
4.  Choose the `main` branch and `/root` folder.
5.  Save the settings.

## 🎨 Website Sections

### Hero

Introduces Noor-e-Saad with the tagline:

> Har Lamha Noor Se Roshan

The hero includes primary and secondary calls to action for planning an
event and viewing the work gallery.

### Services

The website currently showcases:

-   Wedding stages and mandaps
-   Mehndi and dholki nights
-   Birthdays and baby showers
-   Corporate events and launches
-   Entrances and florals
-   Lighting and ambience

### Recent Setups

The gallery includes event concepts for:

-   Weddings
-   Mehndi / dholki
-   Birthdays
-   Baby showers
-   Corporate events

Gallery items can be filtered and opened in an interactive lightbox.

### Event Process

The website explains a four-step workflow:

1.  Consultation
2.  Design
3.  Setup
4.  Event day

### Packages

The site includes three package levels:

-   Essential
-   Signature
-   Grand

Each package can open the booking/request flow.

### Cost Estimator

Visitors can select an event type, guest count, design style, and
optional add-ons. The website then calculates an estimated price range
and can pass the estimate into the booking request.

### Booking Flow

The booking form collects:

-   Name
-   Phone / WhatsApp number
-   Event type
-   Event date
-   Approximate guest count
-   Package preference
-   Additional notes

After validation, the request can be sent through WhatsApp.

## ⚙️ Customization

Before using the website for a real business, update the
business-specific information in `index.html`, especially:

-   Phone / WhatsApp number
-   Social media links
-   Business contact details
-   Service pricing
-   Package pricing
-   Testimonials
-   Business statistics
-   Gallery content
-   Any sample/demo claims

The current design contains sample content and figures intended for the
website concept. They should be replaced with verified Noor-e-Saad
business information before production use.

## 📌 Important

The website currently uses generated/illustrative SVG artwork for the
visual gallery and hero artwork. Real event photography can be
integrated later to make the portfolio more representative of the actual
business.
